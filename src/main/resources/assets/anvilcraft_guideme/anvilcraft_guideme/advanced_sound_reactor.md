# 进阶砧音反应

*砧音反应*共有四类对砧音的需求:
1. 能量
2. 声源数量
3. 音色
4. 氛围

# 能量

最基础的需求，由一个周期内收集到的所有*砧音波*的**响度**之和决定

# 声源

砧音波携带了自己来自何处，<ItemLink id="anvilcraft_reverberation:merge_sound_pillar" />由此判断哪几个地方传来了*砧音波*

# 音色

*砧音波*的**音色**由<ItemLink id="anvilcraft_reverberation:clang_crystal" />下方的方块决定。部分配方需要合音中含有特点的**音色**

# 氛围

**氛围**由[合音](sound_system.md#合音)决定，形式多种多样，下面列举几个简单的**氛围**：
1. 上升：当前周期的合音的能量是上一个周期的两倍以上
2. 下降：当前周期的合音的能量是上一个周期的一半以下
3. 恒定：当前周期的合音的能量和上一个周期的相同

只有少数的配方才会对*氛围*有所要求

# 音序蚀刻

*音序蚀刻*可以被视为多次[砧音反应](sound_system.md#砧音反应)的组合，有点类似于“序列装配”，玩得开心！
